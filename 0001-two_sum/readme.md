Создали пустую таблицу seen 
Получаем число значений в массиве nums и запсиываем его в переменную n
Проходим по массиву nums с индексом i, каждую итерацию увеличивая индекс на единицу 
Для каждого числа nums[i] получаем такое число need, чтобы было верно выражение need = target - nums[i]
Проверяем, есть ли число need в нашей таблице seen:
  - если есть: пара найдена, возвращается значение {seen[need], i}
  - если нет: добавляем текущее число nums[i] и его индекс i в таблицу seen и переходим к следющей итерации 
В случае, если пара не найдена, возвращается пустой вектор
