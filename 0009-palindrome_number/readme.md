# 9. Palindrome Number

## Ссылка на задачу: https://leetcode.com/problems/palindrome-number/description/

## Решение: 
1. Объявили строку `s`, в которую записываем преобразованную в строчный вид переменную `x`
2. Объявляем переменную `r`, равную переменной `s`
3. Реверсим переменную `r` задом наперед с  помощью метода `reverse` 
4. Сравниваем, равны ли между собой `s` и `r`, если да - вернется значение `true`, если нет - `false`
