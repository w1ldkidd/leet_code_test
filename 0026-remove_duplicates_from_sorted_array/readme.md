# 26. Remove Duplicates from Sorted Array

## Ссылка на задачу:  https://leetcode.com/problems/remove-duplicates-from-sorted-array/description/

## Решение: 
1. Проверяем, что массив `nums` не пустой, иначе сразу же возвращаем значение 0
2. Заводим переменную `wr`, изначально равную 0 
3. Циклом проходим по всему массиву `nums`, в цикле заводим переменную `rd`, изначально равную 1:
	1) если выполняется условие, что значение `nums[rd]` не равняется значению `nums[rd - 1]`, те если текущее значение отличается от предыдущего, увеличиваем переменную `wr`
  и перезаписываем в массив `nums` новое уникальное значение на место переменной `wr`, тем самым записывая все уникальные значения друг за другом 
4. После выхода из цикла возвращаем значение `wr + 1`, тк `wr` - индекс последнего уникального числа, количество всегда будет на 1 больше, тк индексы начинаются с 0
