# 55. Jump Game

## Ссылка на задачу: https://leetcode.com/problems/jump-game/description/
## Решение: 
1. Объявили переменную `n` - количество элементов массива `nums`
2. Объявляем переменную `maxReach`, в которую будет записывать максимальное расстояние, на которое мы можем прыгнуть
3. Проходимся циклом по всем элементам массива 
4. Если текущий индекс `i` больше чем `maxReach`, автоматически возвращаем `false`, тк тогда ни с одной пройденной позиции мы не сможем дотянуться до `i`
5. Иначе записываем в `maxReach` наибольшее из значений между самой`maxReach` и  текущим значением максимального прыжка `i + nums[i]`
6. Если `maxReach >= n - 1`, значит последний индекс уже достижим, соответственно возвращаем значение `true`
