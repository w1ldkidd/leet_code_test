# 13. Roman to Integer

## Ссылка на задачу: https://leetcode.com/problems/roman-to-integer/description/?source=submission-noac

## Решение:
1. Создали словарь `value`, содержащий пары чисел в римском и арабском варианте соответственно 
2. Завели переменную `n`, содержащую длину исходной строки `s`
3. Завели переменную `result`, равную 0
4. В цикле проходим по строке `s` с индексом `i`:
  - в переменную `current` записываем текущее число, переменную `next` сделали равной 0
  -  если в строке `s` существует следующее значение, записываем его в переменную `next`
1. Если значение `current` < `next`, отнимаем от значение `result` значение `current`
2. Иначе (если `current > next`), прибавляем `current` к `result`
3. Возвращаем полученное значение `result`
