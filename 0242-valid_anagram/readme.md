# 242. Valid Anagram

## Ссылка на задачу: https://leetcode.com/problems/valid-anagram/description/

## Решение: 
1. Заводим переменные `s_length` и `t_length`, содержащие длину строк `s` и `t`
2. Проводим проверку, если длины строк `s` и `t` не совпадают, они уже не являются анаграммами, следовательно, возвращается `false`
3. Если первое условие не выполняется, сортируем и сравниваем строки `s` и `t`:
	1) в случае, если отсортированные строки идентичны, возвращаем `true`
	2) иначе, возвращаем `false`
