# 14. Longest Common Prefix

**Ссылка на задачу:** https://leetcode.com/problems/longest-common-prefix/

##  Решение 
1. Объявляем строку `result` для записи общего сочетания 
2. Если массив`stsr` пуст - сразу же возвращаем пустой результат 
3. В переменную `n` записываем длину массива 
4. Внешним циклом проходимся по всей длине первой строки 
5. В переменную `c` записываем текущий i-тый символ первой строки
6. Внутренним циклом проходим по следующим строкам, поэтому `j` начинается с 1
7. Внутри цикла проводится проверка на одно из 2 условий:
	1) выход за границы строки ИЛИ
	2) значение i-того символа j-той строки не равно текущему "эталонному" символу из первой строки 
8. Если хотя бы одно из двух условий верно - сразу же возвращается строка `result`
9. Если ни одной из условия не выполнилось, цикл завершается и значение переменной `c` записывается к строке `result` и снова идем в первый цикл 
10. По выходу из цикла возвращается переменная `result`, содержащая самое длинное общее сочетание или пустая, если такого сочетания нет
