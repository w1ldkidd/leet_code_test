# 58. Lenght of Last Word 

## Ссылка на задачу: https://leetcode.com/problems/length-of-last-word/description/
## Решение: 
1. Завели переменную `i`, в которой хранится индекс последнего символа слова 
2. В первом цикле проводим проверку на то, что i-тый символ строки `s` равен пробелу, если выполняется, идем дальше справа налево 
3. Заводим переменную `length` для записи длины последнего слова  в строке 
4. Вторым циклом проходимся справа налево и увеличиваем переменную `lenght`, если i-тый символ строки `s` не равен пробелу 
5. В конце возвращаем переменную `length`
